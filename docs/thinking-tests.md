## 콘텐츠와 데이터

총 30문제이며 수리 / 논리 / 추리 / 공간지각 / 규칙찾기에 각각 6문제입니다. 난이도 분포는 보통(2) 12개, 조금 어려움(3) 16개, 어려움(4) 2개입니다. 쉬움(1)·매우 어려움(5)은 현재 없습니다. 난이도는 편집 기준이며 실제 사용자 풀이 결과로 측정한 수치는 아닙니다.

`data/content/thinking-tests.js`의 `THINKING_TESTS` 배열에서 관리합니다. 필수 필드는 `id`, `category`, `title`, `difficulty`(1~5), `question`, `choices`(중복 없는 4개 문자열), `answer`(0~3), `explanation`입니다. 이미지가 필요한 문제에는 선택 필드 `image`와 `imageAlt`를 추가할 수 있습니다. 현재 30문제 모두 간단한 SVG 조건 그림을 제공합니다. 원문만으로도 풀 수 있으며 그림에는 문제의 주어진 조건만 담습니다. `imageCaption`은 그림 아래 안내입니다.

문제를 추가한 뒤 `node tests/thinking.test.js`에 해당 문제의 독립 풀이도 추가하고 `node scripts/build-seo.js`로 데이터 형식과 사이트맵을 확인합니다. 검사는 독립 검증이 없는 게시 문제가 생기면 실패합니다.

## 화면과 답변보기

목록은 한 페이지에 최대 3줄씩 표시합니다. 데스크톱 3열에서는 9개, 모바일 1열에서는 3개이며 이전·번호·다음 버튼으로 이동합니다. 카테고리를 바꾸거나 모바일 경계를 넘겨 화면 크기를 조절하면 첫 페이지로 돌아갑니다. 카테고리 숫자는 페이지에 표시된 수가 아닌 전체 해당 문제 수입니다. 목록 제목 옆에서 기본순·쉬운순·어려운순을 선택할 수 있습니다. 정렬은 카테고리 필터 적용 후, 페이지를 나누기 전에 수행하며 변경 시 첫 페이지로 돌아갑니다. 같은 난이도에서는 기존 등록 순서를 유지하고, 카테고리를 바꿔도 선택한 정렬은 유지합니다. 홈 추천은 방문마다 중복 없이 무작위 6개를 뽑습니다. 사고력 테스트 목록 상단의 ‘오늘의 테스트’는 무작위 3문제를 추천하며 필터·정렬·페이징을 바꿔도 추천은 유지합니다. 전체보기는 전체 카테고리 첫 페이지로 이동합니다. 별도 중첩 버튼 없이 카드 전체가 해당 문제의 링크입니다.

상세 주소는 기존 `thinking-detail.html?id=math-001` 형식을 유지합니다. `label`과 라디오 `input`으로 ①~④를 선택하고 ‘답변보기’를 클릭합니다. 아무것도 고르지 않으면 ‘답을 하나 선택해주세요.’ 안내와 첫 선택지 초점만 제공하며 답을 공개하지 않습니다.

공개 전에는 정답·선택 답·해설 텍스트를 화면 DOM에 넣지 않습니다. 공개하면 ‘정답입니다!’ 또는 ‘아쉽습니다!’, 내가 선택한 답, 번호를 포함한 실제 정답, 해설을 표시합니다. 정답은 연한 초록, 선택한 오답은 연한 핑크로 표시하고 ‘정답’·‘내 선택 · 오답’ 텍스트도 함께 붙여 색상만으로 구분하지 않도록 했습니다. 공개 뒤에는 입력을 잠급니다.

‘다시 풀기’는 선택, 표시 색, 배지, 정답, 해설, 미선택 안내를 초기화하고 첫 선택지로 초점을 옮깁니다. ‘다음 문제’는 같은 카테고리의 다음 항목으로 이동하며, 마지막 항목에서는 첫 항목으로 순환합니다. ‘사고력 테스트 전체보기’는 항상 제공합니다. 잘못된 ID에는 ‘문제를 찾을 수 없습니다.’와 홈·목록 링크를 표시합니다.

## 문제 그림과 가독성

각 문제의 조건은 문장·줄 단위로 나누고 마지막 물음을 강조합니다. 수리 문제에는 비율·작업 순서·격자를, 논리와 추리에는 상자·카드·집합·타임라인·단서표를, 공간지각에는 이동 경로·전개도·접는 선·회전·좌표·입체도를 제공합니다. 규칙찾기에는 문자 타일과 숫자판을 추가했습니다.

그림 원본은 `scripts/build-thinking-visuals.js`, 생성 파일은 `assets/diagrams/*.svg`입니다. `node scripts/build-thinking-visuals.js`로 30개 SVG와 문제 데이터의 이미지 경로·대체 설명·캡션을 갱신합니다. 문제·보기·정답·해설은 바꾸지 않습니다. 추후 문제를 추가할 때는 해당 문제용 도식도 이 스크립트에 등록할 수 있습니다.

그림은 문제 박스 안에 표시하며 별도의 확대 기능은 제공하지 않습니다. 그림 설명은 하단 중앙에 배치하고, 모든 그림에 텍스트 대체 설명을 제공합니다.

## SEO와 기존 기능

유효 문제마다 제목·카테고리를 포함한 `title`, description, canonical, OG·Twitter 메타데이터, WebPage 구조화 데이터를 설정합니다. 사이트맵에는 30개의 상세 URL을 추가하여 총 88개 URL이 있습니다. 알 수 없는 ID와 ID 없는 주소는 기본 `noindex, follow`를 유지합니다.

기존 심리 테스트의 질문·채점·결과·공유 구현, GA4 ID, AdSense 코드를 변경하지 않았습니다. 추가 CSS는 사고력 테스트 영역에 한정했습니다.

## 통합 검색

검색창은 심리 테스트 50개와 사고력 테스트 30개를 함께 검색하며 전체·심리 테스트·사고력 테스트 필터를 제공합니다. 제목·카테고리·소개 및 사고력 문제 본문·난이도 이름으로 검색할 수 있습니다. 띄어쓰기를 무시하므로 ‘사고력테스트’와 ‘사고력 테스트’가 동일하게 검색됩니다. 정답·해설·선택지는 검색 대상과 결과에서 제외합니다. 통합 검색 데이터는 심리 테스트 랜덤 시작용 목록과 분리했습니다.
