# 사이트 개편 및 사고력 테스트 운영

홈은 두 콘텐츠 소개와 심리 테스트 추천 6개를 보여줍니다. 상단 메뉴는 홈 / 심리 테스트 / 사고력 테스트 / Instagram입니다. 정책 페이지와 기존 결과 화면에도 동일하게 적용했습니다. 명칭은 `사고력 테스트`로 통일했습니다.

- `psychology.html`: 기존 50개 심리 테스트, 카테고리 필터, 페이지 이동, 검색, 랜덤 시작, 주제별 추천과 안내를 유지합니다.
- `thinking.html`: 사고력 테스트 전체 및 수리 / 논리 / 추리 / 공간지각 / 규칙찾기 필터입니다. 수리·논리·추리·공간지각·규칙찾기 각 6개, 총 30문제를 표시합니다.
- `thinking-detail.html?id=...`: 선택지, 답변보기, 정답·오답, 해설, 다시 풀기와 다음 문제를 제공합니다. 제출 전 해설은 DOM에 넣지 않으며 제출 후 답을 잠급니다. 등록되지 않은 ID는 noindex로 처리합니다.

## 문제 추가

`data/content/thinking-tests.js`의 `THINKING_TESTS` 배열에 검수한 문제를 추가합니다. 아래는 필드 형식 예시입니다. 실제로 게시된 30문제는 같은 파일에서 관리합니다.

```js
{
  id: "logic-001",            // 중복 없는 영문 ID
  category: "논리",           // 수리, 논리, 추리, 공간지각, 규칙찾기
  title: "검수한 문제 제목",
  difficulty: 3,              // 1~5 정수
  question: "문제 본문",
  image: null,                // 선택: assets/... 이미지 경로
  imageAlt: "",               // 이미지 문제 설명
  choices: ["선택지 A", "선택지 B", "선택지 C", "선택지 D"],
  answer: 1,                  // 0부터 시작: 1이면 두 번째 선택지
  explanation: "정답의 근거와 풀이"
}
```

목록·홈 추천·풀이 화면은 자동 반영됩니다. 추가 후 `node scripts/build-seo.js`를 실행하면 심리 테스트 정적 링크와 전체 사이트맵을 갱신합니다. 사고력 문제 URL도 사이트맵에 포함됩니다. 이미지가 없으면 문제 본문만 표시합니다.

## 보존 및 SEO

기존 심리 테스트 질문, 점수 계산, 결과·관련 추천 데이터와 Kakao 공유 구현은 유지했습니다. 기존 GA4 ID와 AdSense 코드도 유지했습니다. 기존 `test.html?id=...`와 숫자 ID, 레거시 리다이렉트는 유지합니다. 이전 홈 목록 해시 링크는 심리 테스트 목록으로 연결됩니다.

홈 및 목록의 title / description / canonical / OG를 분리했고 사이트맵에 두 목록 페이지를 추가했습니다. 유효한 사고력 문제는 ID별 메타데이터와 canonical을 설정합니다. 존재하지 않는 문제와 빈 상세 주소는 noindex입니다. robots.txt와 정책 페이지는 유지했습니다.

## 검증 및 배포 후 확인

자동 검사: 콘텐츠, SEO, 라우팅, GA4, 로컬 Chrome 브라우저 검사. 브라우저 검사는 홈 320/390/1200px, 두 목록의 모바일·데스크톱, 사고력 30문제의 네 선택지·미선택·정답·오답·해설·초기화·다음 링크·SEO, 잘못된 ID, 기존 50개 심리 테스트의 결과 진행을 확인합니다. 실제 문제 데이터를 사용하며 검사용 문제를 주입하지 않습니다. 자세한 검증은 [사고력 테스트 구현](thinking-tests.md)을 참고하세요.

배포 후 실제 도메인에서 Kakao 공유, GA4 실시간 수신, AdSense 표시와 Instagram 이동을 직접 확인하세요. 외부 SDK 및 광고 서비스의 실제 요청은 로컬 브라우저 검사에서 제외됩니다. 이번 작업은 로컬 저장소 수정이며 운영 배포는 수행하지 않았습니다.

## 두 목록의 공통 레이아웃

심리 테스트와 사고력 테스트 목록은 배너 → 오늘의 테스트 3개 → 전체 목록 → 이용 안내 순서로 배치합니다. 심리 테스트의 소개·카테고리 설명은 목록 아래에 유지합니다. 카드 너비·여백·열 수와 페이지 버튼 배치를 맞췄으며 두 목록 모두 데스크톱 9개(3열×3줄), 모바일 3개(1열×3줄)씩 표시합니다. 정답 유무에 따른 테스트 진행 방식과 콘텐츠 정보는 그대로 유지합니다.
